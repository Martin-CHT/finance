Sjednocené nastavení

Veškerá konfigurace je společná pro všechny moduly (Příjmy, Spoření, Investice, Půjčky, Fondy, Majetek). Hodnoty se ukládají do cookies prohlížeče a synchronizují se mezi zařízeními přes cloud účet níže.

Cloud účet nepřihlášeno

Přihlaste se uživatelským jménem a heslem — vaše AI klíče, Google Sheets URL, pořadí modulů a téma se automaticky synchronizují mezi všemi zařízeními (PC i telefonem). Účet je uložen v privátním Google Sheetu, heslo se posílá jako PBKDF2 hash (200 000 iterací) — nikdy ne v čistém textu.

Google Sheets synchronizace načítám…

Volitelná záloha všech tvých dat (transakce, cíle, investice, BTC historie, AI klíče) do tvého vlastního Google Sheetu. Žádný server Finance Terminalu data nevidí — komunikuješ přímo s Apps Scriptem, který si nasadíš pod svým Google účtem.

localStorage zůstává primární úložiště — Sheets je jen záloha / synchronizace mezi zařízeními.

Pokud již máš starší verzi Apps Scriptu nasazenou (např. ti vznikl list mod_unknown namísto mod_prijmy, mod_sporeni apod.), nahraď ji celým kódem z návodu níže a klikni Deploy → Manage deployments → Edit (tužka) → New version → Deploy. URL se nemění, jen běží nová verze. Bez redeploye nebudou modulová data v Sheetu (transakce, cíle, půjčky, BTC…) korektně ukládána do svých listů.

URL získáš tak, že podle návodu níže vytvoříš a nasadíš vlastní Apps Script. Aplikace sem sama nic nepřednastavuje — pokud zde URL vidíš, je to z minulosti uložená v cookies (můžeš ji smazat tlačítkem „Smazat veškerá nastavení" dole).

Návod: jak vytvořit Apps Script (5 minut)
  1. Otevři sheets.new — vytvoří se prázdný Google Sheet, který bude úložiště.
  2. V něm klikni Rozšíření → Apps Script.
  3. Smaž vzorový kód a vlož celý kód z rámečku níže. Ulož projekt (Ctrl+S).
  4. Klikni vpravo nahoře Deploy → New deployment. Vyber typ Web app.
    • „Execute as": Me
    • „Who has access": Anyone (jinak prohlížeč nedosáhne)
  5. Klikni Deploy, Google si vyžádá oprávnění → povol pro tvůj účet (uvidí „neověřené" varování, klikni „Pokročilé → Pokračovat", je to tvůj vlastní skript).
  6. Zkopíruj zobrazenou URL končící /exec a vlož ji do pole Web App URL nahoře. Klikni Uložit URL, pak Otestovat spojení.

Token (nepovinné, ochrana): pokud chceš, aby URL bez tvého „hesla" odmítla volání, nastav TOKEN v kódu na libovolný řetězec a stejný vlož níže v Pokročilé. 

/** Finance Terminal — sjednocený Apps Script endpoint.
 *  Ukládá:
 *    - Konfiguraci (AI klíče, téma, pořadí) do listu 'Config'.
 *    - Data každého modulu do listu 'mod_<název>' (např. mod_prijmy, mod_btc).
 */
const SHEET_CONFIG = 'Config';
const TOKEN = ''; // nech prázdné nebo nastav vlastní heslo

function doGet(e) {
  if (!checkToken(e)) return _json({ok:false, error:'bad token'});
  const action = e.parameter.action || 'getConfig';
  if (action === 'getConfig') return _json({ok:true, config: readConfig()});
  if (action === 'getData')   return _json({ok:true, data: readModule(e.parameter.module)});
  return _json({ok:false, error:'unknown action'});
}

function doPost(e) {
  if (!checkToken(e)) return _json({ok:false, error:'bad token'});
  const body = JSON.parse(e.postData.contents || '{}');
  if (body.action === 'saveConfig') { writeConfig(body.data || body.config || {}); return _json({ok:true}); }
  if (body.action === 'saveData')   {
    if (!body.module) return _json({ok:false, error:'missing module'});
    writeModule(body.module, body.data);
    return _json({ok:true});
  }
  if (body.action === 'getConfig')  return _json({ok:true, config: readConfig()});
  if (body.action === 'getData')    return _json({ok:true, data: readModule(body.module)});

  // Legacy POSTy bez 'action' (starý syncToCloud z dřívější verze) — ignorujeme.
  return _json({ok:true, ignored:true, hint:'use action:saveData with module:name'});
}

function checkToken(e) { return !TOKEN || e.parameter.token === TOKEN; }

function readConfig() {
  const sh = _getSheet(SHEET_CONFIG);
  const rows = sh.getDataRange().getValues();
  const cfg = {}; rows.forEach(r => { if (r[0]) cfg[r[0]] = r[1]; });
  return cfg;
}
function writeConfig(cfg) {
  const sh = _getSheet(SHEET_CONFIG); sh.clear();
  const rows = Object.entries(cfg);
  if (rows.length) sh.getRange(1,1,rows.length,2).setValues(rows);
}
function readModule(name) {
  if (!name) return null;
  const sh = _getSheet('mod_' + name);
  const raw = sh.getRange(1,1).getValue();
  if (raw === '' || raw == null) return null;
  try { return JSON.parse(raw); } catch (_) { return raw; }
}
function writeModule(name, data) {
  const sh = _getSheet('mod_' + name); sh.clear();
  sh.getRange(1,1).setValue(JSON.stringify(data));
}
function _getSheet(name) {
  const ss = SpreadsheetApp.getActive();
  return ss.getSheetByName(name) || ss.insertSheet(name);
}
function _json(o) {
  return ContentService.createTextOutput(JSON.stringify(o))
    .setMimeType(ContentService.MimeType.JSON);
}

Pro centrální auth backend (URL FC_AUTH_URL v finance-common.js): pokud chceš, aby fungovala změna hesla a změna jména, musíš do svého auth Apps Scriptu (samostatný projekt, který spravuje účty) přidat tyto dvě akce. Níže je referenční implementace — vlož ji do svého auth scriptu a redeployni pod stejnou URL. 

/** Auth backend — rozšíření pro changePassword + renameUser. */

// V doPost přidej tyto dvě větve PŘED výchozí 'unknown action':
//
//   if (body.action === 'changePassword') return _json(changePassword(body));
//   if (body.action === 'renameUser')     return _json(renameUser(body));

function changePassword(body) {
  // payload: {username, token, oldClientHash, newClientHash}
  const user = body.username, tok = body.token;
  const u = _findUser(user);
  if (!u) return {ok:false, error:'no_user'};
  if (u.token !== tok) return {ok:false, error:'bad_token'};
  if (u.clientHash !== body.oldClientHash) return {ok:false, error:'bad_credentials'};
  // Zapiš nový hash, vystav nový token
  u.clientHash = body.newClientHash;
  u.token = Utilities.getUuid();
  _saveUser(u);
  return {ok:true, token: u.token};
}

function renameUser(body) {
  // payload: {username, token, clientHash, newUsername, newClientHash}
  const u = _findUser(body.username);
  if (!u) return {ok:false, error:'no_user'};
  if (u.token !== body.token) return {ok:false, error:'bad_token'};
  if (u.clientHash !== body.clientHash) return {ok:false, error:'bad_credentials'};
  if (_findUser(body.newUsername)) return {ok:false, error:'user_exists'};
  // Přejmenuj záznam v Auth listu i mod_<user>_* listy
  _renameUserRow(u.username, body.newUsername);
  _renameUserSheets(u.username, body.newUsername);
  u.username = body.newUsername;
  u.clientHash = body.newClientHash;
  u.token = Utilities.getUuid();
  _saveUser(u);
  return {ok:true, token: u.token};
}

// Pomocné — implementace závisí na struktuře tvého Auth listu.
// _findUser / _saveUser / _renameUserRow / _renameUserSheets musíš
// přizpůsobit svému stávajícímu schématu (typicky list 'Auth' s řádky
// username | clientHash | token | config_json).
Pokročilé (Sheet ID, ochranný token)

Apps Script v návodu používá SpreadsheetApp.getActive() — Sheet ID nepotřebuje. Pole vyplň jen pokud máš skript, který otevírá Sheet podle ID (např. centrální skript pro víc Sheetů).

Pokud v Apps Scriptu nastavíš TOKEN = 'něco', vlož sem stejné „něco". Bez správného tokenu skript odmítne každé volání.

Moduly a jejich uspořádání

Pro každý modul nastav skupinu (chlívek na dashboardu) a zda má být zobrazený. Pořadí v rámci skupiny změníš přetažením řádků nebo šipkami. Skupiny lze pojmenovat libovolně — autocompletu pomáhá doporučenými jmény. Změny se aplikují okamžitě na dashboard i na tab bar a synchronizují se mezi zařízeními (pokud jsi přihlášen v cloud účtu).

Vzhled

Tmavý nebo světlý motiv. Volba se přenáší i do otevřených modulů.

Export / import (vše)

Stáhne nebo nahraje úplnou zálohu — konfiguraci (AI klíče, Sheets URL, pořadí, viditelnost, skupiny, téma) i data všech modulů (transakce, předplatná, cíle, půjčky, investice, BTC, broker, energie, majetek). Soubor lze obnovit v jiném prohlížeči bez Google Sheets.

Pokud zaškrtnete Chránit heslem, soubor se zašifruje (AES-GCM 256, klíč z hesla přes PBKDF2 200 000 iterací) — bez správného hesla ho nikdo nepřečte. Doporučeno pro citlivá data.

Zpětná kompatibilita: import přijme i starší soubory bez modulových dat (jen konfigurace).
